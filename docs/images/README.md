# Screen images

These pictures show the Build 44 screens. They are drawn directly from the app's own layout (`res/layout/activity_main.xml`), colours (`res/drawable/`) and button-sizing code (`MainActivity.sizeButtons()`) at a typical 10-inch tablet size (1280 x 800), so a real tablet looks the same apart from button sizes, which adjust to each screen.

The orange "Setup cog" callout is added for the guides; it doesn't appear on the tablet. Names, songs and playlist names are examples.

When the screens change, replace these with fresh pictures or real screenshots (on the tablet, press Power and Volume Down together).
